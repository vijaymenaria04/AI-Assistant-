# Poster & Banner Studio

The studio is accessible from the sidebar. Each design is stored locally in a separate IndexedDB gallery and filtered by workspace. Nothing is seeded. An uploaded logo is local to the current draft/design; selecting another workspace clears the draft after confirmation. Business names are derived from the selected workspace, while the user supplies all headline, details and logo. Check every generated image manually for unintended text, logos, prices, contact information or visual artifacts before publishing. The model cannot guarantee their absence.

You can use your own background image and edit/save/download without an AI service. AI generation sends the entered instructions and up to three explicitly uploaded references to OpenAI only after the user confirms. Do not send sensitive or third-party images without permission.

## AI deployment requirements

The generation route is **disabled by default** and returns 503 unless BOTH `POSTER_IMAGE_API_KEY` (server-side OpenAI key with access to `gpt-image-1`) and `POSTER_TRUSTED_PROXY_SECRET` are set. It requires an `X-GopalAI-Verified-Owner` header matching that secret and applies a small in-process request throttle. This header is **not** a substitute for authentication by itself: a trusted owner-authenticating reverse proxy MUST strip this header from all external requests, authenticate the owner, then inject the server-only shared secret on requests to the private backend. Never expose the backend directly or put the key or proxy secret in browser code. No such proxy or native device authentication exists in this preview, so AI generation intentionally stays unavailable. Deploy only with HTTPS and an authenticated gateway, usage limits and durable rate limiting.

The provider uses the OpenAI Images API; it requires network access to `api.openai.com`. That host is blocked in the current sandbox, and no provider credentials or owner gateway are configured, so a real provider response has not been tested. Voice entry still depends on browser microphone permission; the embedded preview may block it. Sharing depends on the browser/device's Web Share file support. Saved designs are local and are not backed up or synced. The native Android build remains incomplete.

The editor supports replacing the background and logo, choosing image fit, logo position/size, text placement and text/panel colours and opacity. Uploads accept PNG, JPEG or WebP files up to 3 MB each; references are limited to three. The custom canvas is limited to 256–2048 pixels per side; the flex preset is a digital layout, not guaranteed print-ready artwork. Users should verify print resolution with their printer. Voice language can be chosen independently of the app UI language; Hindi/Hinglish recognition is best effort and depends on the browser speech service.
